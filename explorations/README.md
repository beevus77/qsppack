# Explorations

This directory contains research history and the current paper-figure staging
area. It is not part of the supported `qsppack` API. Public examples must import
from `qsppack` and live under `docs/source`; reusable numerical code belongs in
the package with tests.

Do not add new package implementations here. In particular, the maintained
Remez and retraction interfaces are now `qsppack.remez` and `qsppack.retract`.

The cleanup classification, publication blockers, and removal gates are listed
in [CLEANUP_MANIFEST.md](CLEANUP_MANIFEST.md). The commands and inputs for the
paper figures remain in [recovery/FIGURES.md](recovery/FIGURES.md) until their
remaining workflows have been migrated or archived.
